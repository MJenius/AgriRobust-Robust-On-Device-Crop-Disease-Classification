# Phase: 0 — Project Contract and Environment

## Objective
Initialize reproducible project infrastructure and freeze the project specification.

## Allowed Work
- repository setup
- environment setup
- configuration
- dataset registry/specification
- metric specification
- reproducibility conventions
- tests for setup

## Not Allowed
- dataset training
- teacher training
- student training
- knowledge distillation
- robustness experiments
- quantization
- Android implementation

## Exit Criteria
- environment is reproducible
- repository structure exists
- dataset registry exists
- metric specification exists
- project configuration exists
- tests pass
- all unresolved assumptions are documented
