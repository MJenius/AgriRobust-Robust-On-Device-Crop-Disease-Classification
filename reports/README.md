# AgriRobust Reports Directory

This directory stores phase reports, decision records, validation logs, and benchmark summaries.

## Contents

- `phase_00_decisions.md`: Phase 0 decision log, environment audit, verified facts, and deferred items.
- `phase_01_datasets.md`: Phase 1 dataset foundation report, split manifests, and integrity audits.
- `phase_02_teacher.md`: Phase 2 teacher baseline report, model selection, multi-seed evaluation, efficiency benchmarks, and frozen reference specification.
- `phase_03_student.md`: Phase 3 compact student baseline report, MobileNetV3-Small architecture selection, end-to-end fine-tuning without distillation, and quantified teacher-student gap analysis.
- Future phase reports (`phase_04_distillation.md`, `phase_05_robustness.md`, etc.) will document each phase's outcomes and verification artifacts before passing phase gates.
